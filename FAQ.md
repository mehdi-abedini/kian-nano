# FAQ

## What is this repository?

Kian Nano Karno Research Agent is a public research-infrastructure and orchestration layer. It is designed to decompose research questions, route capabilities, collect and structure evidence, validate computable claims, and produce reproducible technical outputs.

It is not presented as a complete autonomous AI system.

## What can I verify locally?

A clean Python environment can verify package installation, compilation, registry integrity, the regression suite, and deterministic CLI examples.

See [docs/REVIEWER_GUIDE.md](docs/REVIEWER_GUIDE.md) for the shortest verification path.

## Is this an autonomous trading bot?

No. It is a research and analysis workflow. Trading research must include point-in-time controls, costs, slippage, risk, survivorship controls, and out-of-sample validation.

## Does it contain Kian Nano Karno trade secrets?

No. Public repositories should contain reusable workflow logic and public-safe evidence only. Confidential formulations, contracts, credentials, unpublished invention disclosures, customer information, and patent-sensitive implementation remain outside this repository.

## Can it use scientific databases?

Yes, when the runtime provides an approved connector, API, web source, or other authorized tool. The repository itself does not grant access to a database or imply that a source is authoritative.

## Can it use GitHub skills or external agents from other projects?

Potentially, after supply-chain review. A discovered repository, skill, MCP server, model, dataset, or executable tool is not automatically trusted or authorized.

Review should consider provenance, license, version, security, reproducibility, maintenance status, and applicability.

## Can it cover Iran and Tehran Stock Exchange research?

Yes, when reliable jurisdiction-specific data is available. Iranian market conventions, local disclosures, calendars, and data providers must be handled separately from assumptions derived from US or other markets.

## Can it generate papers and patents?

It can support literature synthesis, drafting, prior-art analysis, technical reporting, and research planning. It does not replace scientific peer review, inventorship analysis, patent counsel, or legal review.

## What does confidence mean?

Confidence describes evidentiary support and uncertainty. It should not be interpreted as a calibrated probability of correctness unless a validated statistical model supports that interpretation.

## Does passing CI prove scientific correctness?

No. CI establishes only the software properties actually tested by the workflow. Scientific validity, clinical efficacy, field performance, manufacturability, financial returns, and other domain outcomes require independent domain evidence.

## Why is some implementation private?

The public repository is intentionally separated from confidential company infrastructure and intellectual property. Public documentation may describe an architectural boundary without proving every property of the private implementation.
