# FAQ

## Is this an autonomous trading bot?
No. It is a research and analysis workflow. Trading research must include point-in-time controls, costs, slippage, risk, and out-of-sample validation.

## Does it contain Kian Nano Karno trade secrets?
No. Public repositories should contain reusable workflow logic, not confidential formulations, contracts, credentials, or unpublished invention disclosures.

## Can it use scientific databases?
Yes, when the runtime provides approved connectors, APIs, web access, or other tools. The skill itself does not grant access to a database.

## Can it use GitHub skills from other projects?
Yes, after repository and supply-chain review. A discovered skill is not automatically trusted or authorized.

## Can it cover Iran and Tehran Stock Exchange research?
Yes, when reliable jurisdiction-specific data is available. Iranian market conventions and data sources must be handled separately from US-market assumptions.

## Can it generate papers and patents?
It can support research synthesis, drafting, prior-art analysis, and technical reporting. Claims must remain traceable to evidence and should receive human/legal review where required.

## What does confidence mean?
Confidence describes evidentiary support and uncertainty, not a probability of correctness unless a calibrated statistical model is actually used.
