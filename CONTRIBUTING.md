# Contributing

## Before changing the skill
- Keep SKILL.md focused on routing and workflow.
- Put detailed domain knowledge in references.
- Put deterministic validation in scripts.
- Add or update evaluation prompts for trigger behavior.
- Do not add secrets or confidential company information.

## Validation
Check:
1. YAML frontmatter.
2. Referenced files.
3. Evaluation prompts.
4. Security review.
5. Documentation consistency.
6. Git diff and repository status.

## Pull requests
Describe the behavior changed, evidence used, tests performed, and known limitations.
