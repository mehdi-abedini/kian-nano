# Design Intelligence Reference

## Purpose

This module routes design-related research through the Kian Nano Karno design contract. It applies to landing pages, Academy, Figma, WordPress/Elementor, UI systems, visual identity, and design-agent workflows.

## Mandatory reading

For design tasks, read:
- design/KKN_DESIGN_CONTRACT.md
- design/DESIGN.md
- registry/design_sources.yaml
## External-source discipline

External design repositories and first-party systems are research inputs. Preserve:
- source URL
- source type
- retrieval date
- version/commit when available
- license
- provenance confidence
- extracted principle
- KKN relevance
- adoption status

Never copy a brand's signature visual language. Extract principles, test them against KKN requirements, and synthesize an original result.

## Design workflow

Research → provenance check → principle extraction → KKN synthesis → token/component proposal → visual validation → implementation handoff → human approval → publication.
## Validation

Every design proposal should consider:
- RTL/LTR
- accessibility and keyboard behavior
- responsive layout
- reduced motion
- scientific typography and notation
- evidence/citation visibility
- performance
- SEO
- maintainability
- visual consistency
- similarity/copy risk

## Production boundary

Research and draft implementation may proceed autonomously where tools permit. Production publication or irreversible website mutation remains approval-gated.
