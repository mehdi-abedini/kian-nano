# Kian Nano Karno Genomics & NGS Research Agent

## What this module is
The Kian Nano Karno Research Agent includes a dedicated genomics/NGS/bioinformatics workflow for evidence-grounded research across whole-genome and exome sequencing, RNA-seq, long-read sequencing, single-cell and spatial omics, population genomics, and genomic AI.

## How it works
**Question → study design → data governance → reference lock → QC → reproducible pipeline → benchmark → statistical inference → biological validation → replication → publication/IP gate**

The agent does not treat a model prediction or automated annotation as experimental evidence. Material claims are linked to dated sources, calculations, user-provided data, or explicitly labeled hypotheses.

## Benchmark-first research
The workflow uses public benchmark resources before confidential project data where appropriate. Current benchmark infrastructure includes NIST Genome in a Bottle and its newer HG002/T2T-linked resources, plus task-specific benchmark suites for variants, spatial analysis, and genomic foundation models. ## Agentic genomics
The agent can evaluate external genomics agents rather than blindly adopting them. For example, Genentech's SpatialAgent demonstrates a plan-act-conclude architecture with specialized tools for spatial biology; SpatialBench provides verifiable spatial-analysis tasks with deterministic graders; and a 2026 Genome Biology benchmark evaluates LLM-based agents across 50 real-world single-cell omics tasks. These are used as evaluation references, not as evidence that any agent is universally reliable. citeturn0search5turn0search6turn0search4

## Genomic foundation models
Foundation models are evaluated by task and data regime rather than by a single global score. GENEB is a current benchmark covering 40 genomic foundation models, 100 DNA classification tasks, and 13 functional categories under a controlled frozen-embedding protocol. citeturn0search7

## Data protection
Human genomic data, unpublished company datasets, credentials, and trade secrets remain outside the public repository and public-facing research layer unless explicitly authorized.

## Scientific boundary
The agent supports research and analysis. It does not by itself establish a diagnosis, pathogenicity classification, causality, clinical performance, or therapeutic efficacy. Those require the appropriate validation and governance pathway.
