# Help

## Quick start
Install the skill, then request a task in natural language.

### Research
"Investigate [question]. Search primary sources, compare conflicting evidence, and produce a reproducible report."

### Industrial R&D
"Analyze [process]. Define KPIs, critical parameters, instrumentation, scale-up risks, and acceptance tests."

### IP
"Map the prior art for [technology]. Separate novelty evidence from FTO/legal conclusions."

### Finance
"Analyze [company/market]. Use dated primary financial data and separate facts from interpretation."

### Trading research
"Backtest [strategy] using point-in-time data, transaction costs, slippage, survivorship controls, and out-of-sample validation."

## Output controls
Ask for:
- executive summary only
- full technical report
- evidence table
- uncertainty analysis
- reproducibility package
- experiment plan
- patent/prior-art matrix
- investment research memo

## Escalation
If evidence is missing, contradictory, or too weak for the requested conclusion, the agent must state what is missing rather than filling gaps with assumptions.
